# Bảng thuật ngữ

| Thuật ngữ | Ý nghĩa |
| --- | --- |
| AI Planner | Workflow nhiều giai đoạn chuyển source đã xác minh và ràng buộc thành lịch trình có cấu trúc |
| Artifact | Phần nội dung được phép lấy từ nguồn, như metadata, caption, transcript hoặc frame reference |
| Plan dự phòng | Phương án riêng liên kết với plan chính; không bao giờ ghi đè plan chính |
| Buyer | User mua một listing trên Marketplace |
| Creator | User xuất bản và bán plan du lịch |
| Entitlement | Bằng chứng phía server cho phép user truy cập nội dung đã mua |
| Explorer | Bước Planner chuẩn hóa ý định và đặt câu hỏi làm rõ |
| Importer | Pipeline tiếp nhận URL, lấy nội dung được phép và tạo artifact có provenance |
| Finder | Bước Planner chọn/điền địa điểm và khung giờ |
| Ràng buộc cứng | Yêu cầu không được vi phạm, ví dụ khả năng tiếp cận hoặc giờ cố định |
| Host | User sở hữu/tổ chức trip và quản lý thành viên |
| Lịch trình / plan | Các ngày, địa điểm, hoạt động, phương tiện, thời gian, chi phí và ghi chú có thứ tự |
| Listing | Sản phẩm Marketplace gồm preview, giá, license và phiên bản plan đã publish |
| Item đã khóa | Mục lịch trình mà AI bắt buộc phải giữ nguyên khi chỉnh sửa lại |
| Macro plan | Tên và chủ đề cấp cao của từng ngày trước khi điền địa điểm chi tiết |
| Plan chính | Lịch trình chính được user chọn |
| Place candidate | Tên địa điểm thô được trích xuất, chưa phải địa điểm user đã xác nhận |
| Place Resolver | Thành phần đối chiếu candidate với địa điểm chuẩn hóa từ provider |
| Selected place | Địa điểm đã được user xác nhận và chọn làm đầu vào Planner |
| Source claim | Thông tin trích xuất từ nguồn, kèm evidence và confidence; chưa mặc định là sự thật hiện tại |
| Unscheduled place | Địa điểm đã xác nhận nhưng chưa thể xếp vào plan, kèm lý do |
| Bản sao cá nhân | Trip có thể chỉnh sửa được tạo cho buyer từ một phiên bản đã mua và bất biến |
| Kiểm tra plan | Kiểm tra tính khả thi, độ mới và rủi ro bằng quy tắc/provider |
| Phiên bản plan | Snapshot bất biến dùng để publish, mua, so sánh hoặc khôi phục |
| Provenance | Nguồn và ngữ cảnh truy xuất hỗ trợ một địa điểm, claim hoặc item |
| Remix | Sản phẩm phái sinh thương mại từ plan creator theo license rõ ràng |
| Traveler | User lập kế hoạch hoặc đi du lịch; cũng có thể là host hoặc buyer |
